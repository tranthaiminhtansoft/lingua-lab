Procedures

Start here Product guide Reference Procedures

Follow these operator guides in order for a planned production release. Each step is a separate page so you can keep the relevant checklist open while working.

  1. Pre-release: check readiness and record the intended commit and recovery plan.
  2. Release: trigger the workflow, inspect evidence, and make the two explicit production approval decisions.
  3. Post-release: visit the deployed site and record route-level checks.

Rollback and recovery

Use only when the release owner authorizes returning production to a published stable release, or when the release workflow directs you there.

Live application

Open the currently deployed product separately from the workflow configuration and its run evidence.

These procedures describe actions and decision points. For workflow design, configured checks, and technical boundaries, see the Delivery reference. Never treat a configured workflow or a green summary alone as proof that production is healthy.
