Product Guideline

Start hereProduct GuidelineReferenceProcedures

Lingua Lab is a multi-language learning workspace. It helps people learn independently through practical activities drawn from everyday life, making learning feel familiar and easier to remember. Current language examples include Japanese and English.

Prerequisites and install

RequirementDetails
Node.jsUse version 22.22.2, pinned in .nvmrc.
DependenciesInstall from the repository root using the committed npm lockfile.
Working directoryRun all commands below from the repository root.
  1. Confirm the selected Node.js and npm versions with node --version and npm --version. Node.js should report v22.22.2.
  2. Install the locked dependencies with npm ci. This replaces the existing node_modules directory.
  3. Start the local application with npm run dev, then open the URL printed by Vite.

Local checks

Run these from the repository root; each check covers a different concern.

npm run lint
npm run typecheck
npm run test:unit -- --run
npm run build
  • lint runs ESLint.
  • typecheck runs tsc -b --pretty false.
  • The unit-test command runs Vitest once; its configuration uses jsdom and excludes e2e/**.
  • build type-checks, builds the Vite app, then exports these documentation pages to dist/docs. A build is not a deployment.

Browser checks

The configured end-to-end suite uses Chromium, Firefox, and WebKit, and starts its own server after building with GITHUB_ACTIONS=true.

npx playwright install chromium firefox webkit
npm run test:e2e

The test harness serves the Pages-style artifact under http://127.0.0.1:4176/lingua-lab/ and covers navigation, lessons, narrow screens, and a Kana deep-link refresh. Port 4176 must be available; outside CI, Playwright may reuse an existing server there.

Pages-style local preview

GITHUB_ACTIONS=true npm run build
GITHUB_ACTIONS=true npm exec -- vite preview

Open the printed preview URL with /lingua-lab/. A local preview does not establish live Pages behavior or production deployment. The site's public/404.html provides the configured deep-link fallback; use the E2E server for its local model.

Interpreting results: The commands above are instructions, not claims that they passed on this revision. Record runtime versions, command, exit status, and failures. A local build or browser test is not production verification or release approval.
