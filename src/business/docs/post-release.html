Post-release

Start hereProduct guideReferenceProcedures

After publication, check the deployed site directly; workflow success and live behavior are separate evidence.

  1. Open the Pages URL returned by the successful deployment: https://tranthaiminhtansoft.github.io/lingua-lab/.
  2. Test the home page, then representative routes such as /nihongo-o-benkyuo/kana, /nihongo-o-benkyuo/grammar, and /nihongo-o-benkyuo/vocabulary. Refresh a nested route and note any failures.
  3. For Vocabulary → Time, open /nihongo-o-benkyuo/vocabulary/time and refresh. Confirm the fixed sample date October 15, 2026, drag both clock hands, check the combined Kana/Romaji, and try a.m./p.m., half past, the section menu and Top on mobile. The release verification artifact includes time-results.json and failure screenshots when a check fails.
  4. Record the URL, date/time, routes tested, and observed outcome. Escalate errors; do not call the release healthy based only on HTTP status or workflow completion.
  5. If the spot-check fails, pause further release activity and have the release owner decide next steps. If rollback is authorized, follow the standalone Rollback guide.
