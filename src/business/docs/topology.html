Routes and composition

src/app/main.tsx mounts the router from src/app/router.tsx. The pathless AppShell wraps the learning routes with shared navigation.

  • / — Language selection home
  • AppShell
    • /nihongo-o-benkyuo — Nihongo hub
    • /nihongo-o-benkyuo/kana — Kana reference and practice
    • /nihongo-o-benkyuo/grammar — Grammar hub
      • /nihongo-o-benkyuo/grammar/first-introductions — First introductions
      • /nihongo-o-benkyuo/grammar/question-types — Question types
    • /nihongo-o-benkyuo/numbers — Numbers
    • /nihongo-o-benkyuo/vocabulary — Vocabulary hub
      • /nihongo-o-benkyuo/vocabulary/first-introductions — First introductions
      • /nihongo-o-benkyuo/vocabulary/time — Time
    • /lessons/kana — Legacy route; redirects to /nihongo-o-benkyuo/kana
    • * — Not found

Runtime boundaries

  • GitHub Pages serves static HTML, CSS, JavaScript, and bundled lesson data/assets.
  • React and route selection execute in the visitor's browser; no application backend or app-owned API is configured in the inspected app.
  • Build and deployment jobs belong to the control plane, not the runtime.
  • Vite uses / locally and /lingua-lab/ when GITHUB_ACTIONS is set. React Router uses Vite's base URL as its basename.

The configured public/404.html fallback restores deep paths under the project base. The repository E2E harness models that behavior; live Pages behavior is not established by this source inspection.
